# Мой дом мечты

Сайт для школьного проекта Паши Карася. Двухэтажный дом площадью 240 м², включая террасу: интерактивный план, подробные описания 11 пространств, авторские SVG-интерьеры и анимированный CSS-фон со звёздами в трёх слоях глубины.

## Как открыть готовый сайт без установки программ

Откройте `index.html` в корне проекта двойным щелчком в браузере: стили, скрипты, шрифт и изображения уже встроены в файл. Интернет и Node.js для просмотра не нужны. Копия той же готовой страницы находится в `ready-site/index.html`.

Если проект уже сохранён в GitHub, на странице репозитория выберите **Code → Download ZIP**, распакуйте архив и откройте `index.html` из распакованной папки.

Команда `npm run build` автоматически обновляет обе готовые страницы. Их не нужно редактировать вручную: исходная разметка находится в `dev.html`.

## Разработка

Требуется Node.js 20.19+ или 22.12+ (в облачной среде проверено с Node.js 24).

```sh
cd /workspace/school-site
npm ci
npm run dev -- --port 5173
```

Для локальной работы вне облачной среды перейдите в папку репозитория вместо `/workspace/school-site`.

```sh
npm run build   # сайт в dist/ и готовые автономные HTML-страницы
npm run preview # проверка собранной версии
npm test        # сборка и функциональные проверки в Chromium
```

Тесты автоматически запускают и останавливают сервер собранного сайта. Они используют `/usr/bin/chromium`, если он доступен; другой установленный Chromium можно указать через `CHROMIUM_PATH`. На машине без браузера выполните `npx playwright install chromium` (на Linux для системных библиотек может потребоваться `npx playwright install --with-deps chromium`).

## Как показывать на интерактивной доске

- Кнопка «Презентация» открывает 13 слайдов с крупным текстом и кнопками. Значок разворачивания включает полноэкранный режим, если браузер его поддерживает.
- Стрелки на клавиатуре переключают слайды, Home и End открывают первый и последний, Esc закрывает презентацию. На сенсорном экране используются кнопки «Далее» и «Назад».
- На плане можно выбрать этаж и нажать любую комнату. «Заглянуть в комнату» открывает её полную историю; «На плане дома» возвращает к нужному этажу.
- Значок звезды в шапке приостанавливает анимацию. Системная настройка уменьшения движения также учитывается.

## Содержимое

Первый этаж: гостиная 40 м², кухня-столовая 28 м², прихожая 14 м², кабинет 18 м², гостевая ванная 12 м² и терраса 20 м². Всего 132 м².

Второй этаж: спальня родителей 24 м², моя комната 28 м², гостевая 22 м², семейная ванная 14 м², гардеробная и холл 20 м². Всего 108 м².

План — условная авторская схема для школьного проекта. Тексты, данные комнат, иконки, иллюстрации и логика находятся в `src/main.js`, оформление — в `src/style.css`, исходная структура страницы — в `dev.html`. `index.html` и `ready-site/index.html` создаются скриптом `scripts/export-standalone.mjs`.

Все изображения и шрифты хранятся локально; во время просмотра сайт не обращается к сторонним сервисам. Изображение дома создано специально для проекта. Manrope распространяется по SIL Open Font License, текст лицензии находится в `public/fonts/OFL.txt`.
